# @bull/create

Creates a new [Bull](https://github.com/nicolasandradedesarrollosit/bull) project, the opinionated
React framework that refuses to build unless you respect MVVM.

```bash
npm create @bull@latest my-app
pnpm create @bull my-app
yarn create @bull my-app
bun create @bull my-app
```

Without a name it asks for the details. It installs the dependencies with the package manager you
ran it with and initializes a git repository; skip either with `--no-install` or `--no-git`.

It is the same command as `bull create`, from [`@bull/cli`](https://www.npmjs.com/package/@bull/cli).
